# Reliance Smart Sales Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze retail sales performance across products, regions, stores, and customer segments.

The dashboard enables business users to monitor key performance indicators (KPIs), evaluate product performance, analyze regional sales trends, and track return metrics.

---

## Business Objective

The objective of this project is to provide a centralized sales reporting solution that helps decision-makers answer questions such as:

- Which products generate the highest revenue and profit?
- Which regions contribute the most sales?
- How do returns impact business performance?
- Which locations drive the highest transaction volume?
- How do key business metrics perform compared to previous periods?

---

## Tools Used

- Power BI
- DAX

- Data Modeling

---

## Dataset

The project uses multiple datasets:

- Calendar
- Customers
- Products
- Regions
- Stores
- Returns

The datasets were integrated through a star-schema data model.

---

## Dashboard Features

### KPI Cards

- Total Transactions
- Total Revenue
- Total Profit
- Total Returns

### Product Analysis

- Product Brand Performance
- Revenue by Product
- Profit by Product

### Regional Analysis

- Region-wise Revenue
- State-wise Transactions
- Country-wise Performance

### Returns Analysis

- Return Quantity
- Return Trends
- Return Rate Monitoring

### Geographic Analysis

- Interactive Map Visualizations
- Regional Sales Distribution

---

## Key Insights

- Revenue and profit can be monitored against previous periods.
- Certain states contribute significantly more transactions than others.
- Product-level analysis helps identify top-performing brands.
- Geographic analysis highlights regional sales concentration.
- Return tracking helps evaluate operational performance.
